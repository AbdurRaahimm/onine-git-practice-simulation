# onine-git-practice-simulation

Static site published with [One Click Deploy](https://github.com/AbdurRaahimm).

**Live URL:** https://AbdurRaahimm.github.io/onine-git-practice-simulation/

## What's included

- GitHub Pages enabled on `main`
- `.nojekyll` so assets aren't processed by Jekyll
- `404.html` fallback
- `robots.txt` + `sitemap.xml`
- GitHub Actions workflow at `.github/workflows/pages.yml` so every push re-publishes

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
